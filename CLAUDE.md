# Nomogenesis verification

Read `README.md` and `AGENTS.md` first. Run `npm ci` followed by
`npm run verify` for a fresh local NEAR Sandbox lifecycle. Run
`npm run verify:evidence` for the recorded public Testnet artifacts.

Do not start `--live`, resend transactions, or rely on historical worklog
status. State the actual exit codes and distinguish locally reproduced
behavior from recorded public Testnet evidence.
