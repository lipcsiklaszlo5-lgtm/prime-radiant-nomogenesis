# Release checklist

- [ ] Clean checkout and final commit recorded.
- [ ] Rust, Python and Sandbox checks rerun.
- [ ] Every claim has a command and observed result.
- [ ] Secrets, local paths and generated output removed.
- [ ] Development-only/session-only instructions reviewed.
- [ ] Temporary instructions removed or rewritten as normal contributor documentation.
- [ ] Product specs, security evidence and limitations preserved.
- [ ] README explains exactly what to run and what the judge sees.
- [ ] Final release commit is separate and owner-approved.
